## 👋 Hallo, ik ben Lars

Leuk dat je hier bent! Ik ben iemand die graag dingen **uitzoekt, bouwt en aan de praat houdt** — techniek is echt mijn ding.

- 🏊 **ICT-beheerder** bij de zwemvereniging — ik houd het leerlingvolgsysteem draaiend, help vrijwilligers via de servicedesk en beheer de website.
- 🎓 **Fulltime student** aan de ICT Academie, altijd bezig met de uitdagingen van morgen.
- 🏠 **Home automation-fan** — ik maak met slimme automatiseringen een slim huis nóg slimmer.
- 🌐 Ik bouw graag nette, interactieve **websites** (kijk maar op [larsmeneer.nl](https://larsmeneer.nl)).
- 🤖 Sparren, code schrijven en ideeën uitwerken doe ik graag samen met **Claude**.

> *Computers zijn geweldig: ze doen precies wat je ze opdraagt.* 😄
